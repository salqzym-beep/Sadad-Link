# سداد لينك — النسخة المحدثة

## الملفات
- `index.html`: واجهة العميل.
- `admin.html`: لوحة الإدارة.
- `api/[...path].js`: واجهات الخادم وربط Firebase Firestore.

## متغيرات Vercel المطلوبة
1. `FIREBASE_SERVICE_ACCOUNT_JSON`: محتوى ملف Service Account JSON كاملًا (سرّي، لا تضعه في ملفات الواجهة).
2. `SESSION_SECRET`: سلسلة عشوائية طويلة لا تقل عن 32 حرفًا.

أضف المتغيرين إلى Production وPreview وDevelopment عند الحاجة، ثم أعد النشر.

## أول تشغيل
افتح `/admin.html`، وستظهر شاشة إنشاء المدير الأول مرة واحدة. استخدم كلمة مرور قوية (10 أحرف على الأقل). بعدها يستطيع المدير إضافة مدراء آخرين.

## ملاحظات مهمة
- بيانات العملاء والأرصدة والطلبات تحفظ في Firestore على الخادم، ولا تحفظ كلمات المرور كنص صريح.
- يجب أن تكون قواعد Firestore مغلقة أمام الوصول المباشر من المتصفح؛ الخادم يستخدم Firebase Admin SDK.
- أضف فهارس Firestore إذا طلبها سجل التنفيذ عند استخدام استعلامات مركبة.
- هذه النسخة لا تتصل تلقائيًا بمزودي الاتصالات أو جهات الماء والكهرباء؛ الطلبات تسجل وتنتظر تنفيذ الإدارة، ثم ترسل الإدارة تحديث الحالة للعميل.
- اختبرها أولًا ببيانات تجريبية قبل استقبال أموال حقيقية.
